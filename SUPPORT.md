# Getting Help

Gold Digger is a single-maintainer open-source project. Here is how to get help.

## Asking Questions

- **GitHub Issues**: Open an [issue](https://github.com/EvilBit-Labs/gold_digger/issues) for bug reports, feature requests, or general questions about usage.
- **GitHub Discussions**: If the repository has Discussions enabled, use them for open-ended questions and community conversation.

## Response Times

As a single-maintainer project, response times depend on severity:

- **Critical/High security issues**: 24-48 hours (see [SECURITY.md](SECURITY.md))
- **Bug reports**: 3-5 business days
- **Feature requests and questions**: 1-2 weeks

## Documentation

- **User guide**: The [mdbook documentation site](https://evilbit-labs.github.io/gold_digger/) contains detailed usage instructions and architecture notes.
- **Source docs**: The [`docs/`](docs/) directory contains the documentation source files.
- **API reference**: Run `cargo doc --open` to generate and browse Rust API documentation locally.
- **Contributing**: See [CONTRIBUTING.md](CONTRIBUTING.md) for development setup and contribution guidelines.

## Security Issues

**Do not open a public issue for security vulnerabilities.** Follow the private disclosure process described in [SECURITY.md](SECURITY.md).
